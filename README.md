## 📖 About This Repository

This repository contains detailed write-ups of CTF challenges I have solved across various platforms. Each write-up documents my thought process, tools used, mistakes made, and lessons learned — not just the final answer.

Each challenge entry includes:
- Platform & challenge name
- Category and difficulty
- Problem description
- Approach & methodology
- Tools used
- Solution script / commands
- Key takeaways
